# カタン ランダム盤面

カタン（3〜4人用・基本セット）の盤面をランダムに作って、画面いっぱいに表示するページです。

- 地形19枚（木4・レンガ3・羊4・小麦4・石3・砂漠1）をシャッフル
- 数字チップ18枚をシャッフル（砂漠には置かず、盗賊を置く）
- 港は枠パーツ6枚の並び順をシャッフル（小麦・レンガ・羊のパーツは1番目の辺に3:1＋4番目の辺に2:1、石・木・3:1のパーツは3番目の辺に港1つ）
- 「新しい盤面」ボタンで作り直し
- 縦長の画面では盤面を90度回して大きく表示

公開ページ: https://chan1018.github.io/catan-board/
